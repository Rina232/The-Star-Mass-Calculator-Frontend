# The Star Mass Calculator (Frontend)

Для запуска
```bash
npm install
npm run generate-api
npm run dev
```

Приложение будет доступно по ссылке: http://localhost:3001

## Меню

Нижняя панель `Navbar` из 4 пунктов:

| Пункт | Маршрут | Состояние |
|---|---|---|
| Лента | `/feed` | доступен |
| Добавить | `/add` | доступен только после входа |
| Каталог | `/catalog` | доступен |
| Вход | `/login` | после входа заменяется на «Выход» |

## Страницы

### Лента (`/feed`, `/feed/:id`)

Без `id` открывается первая опубликованная услуга, с `id` - выбранная. Если услуги нет или она не опубликована, показывается сообщение и кнопка «В каталог».

Элементы:
- видео на весь экран; если `videoUrl` пустой или не загрузился, воспроизводится видео по умолчанию;
- изображение; если `imageUrl` пустой или не загрузился, показывается изображение по умолчанию;
- справа: кнопка лайка с количеством, средняя масса (M⨀), средняя светимость (L⨀);
- лайк доступен только вошедшему пользователю, у гостя кнопка заблокирована; поставленный лайк подсвечивается, повторное нажатие снимает его;
- кнопка «Следующий» (стрелка вниз) - запрос следующей опубликованной услуги, после последней - первая;
- внизу: название и описание, кнопка «ещё…» / «свернуть» разворачивает и сворачивает описание.

### Каталог (`/catalog`)

Плитка опубликованных услуг в 2 столбца. Карточка: изображение, название, количество лайков, кнопка «Подробнее»; клик по карточке или кнопке открывает ленту с этой услуги. Для вошедшего пользователя сверху показывается его имя.

Фильтр по массе:
- два ползунка `min` и `max` (0-25 M⨀, шаг 0,1), минимум не может превысить максимум;
- значения хранятся в Redux, кнопка «Найти» отправляет их в запрос к бэкенду (`minMass`, `maxMass`);
- при выходе из аккаунта фильтр сбрасывается;
- если ничего не найдено, выводится «По заданным параметрам ничего не найдено».

Удаление: на своих карточках вошедший пользователь видит кнопку удаления, после удаления список загружается заново.

Услуги в статусах `draft` и `deleted` не отображаются.

### Добавление (`/add`)

Страница доступна только вошедшему пользователю, гостя перенаправляет на `/login`. Создание происходит в два шага.

Шаг 1, медиа:
- название (от 3 символов), файл изображения, файл короткого видео;
- кнопка «Далее» создаёт черновик (`POST /api/star-classes`);
- если у пользователя уже есть черновик, он загружается при открытии страницы, название и превью показываются, поля файлов скрываются.

Шаг 2, информация (появляется, когда есть черновик):
- краткое описание, масса (M⨀), светимость (L⨀);
- кнопка «Опубликовать» активна, когда все поля заполнены корректно; после публикации открывается лента на новой услуге;
- ошибки бэкенда (например, 409 при повторном создании черновика) выводятся над формой.

### Авторизация (`/login`)

Одна форма с переключением между входом и регистрацией:
- поля: имя пользователя и пароль (при регистрации: от 3 и от 4 символов соответственно);
- «Войти» отправляет `POST /api/users/login`; «Зарегистрироваться» сначала регистрирует пользователя, затем сразу входит;
- при успехе в Redux записываются `id` и имя пользователя, открывается каталог; если пользователь уже вошёл, страница перенаправляет в каталог;
- ошибки: неверный логин или пароль (401), недоступность сервиса, ошибки регистрации;
- выход: пункт «Выход» в меню отправляет `POST /api/users/logout`, сбрасывает состояние пользователя и фильтр и возвращает гостевой интерфейс.

Запросы входа, регистрации и выхода выполняются только через axios (`src/api/authApi.ts`), без кодогенерации и thunk; состояние в Redux меняется вручную. Сессия хранится в cookie `sessionId`: после обновления страницы (F5) Redux возвращается в состояние гостя, а cookie остаётся.
