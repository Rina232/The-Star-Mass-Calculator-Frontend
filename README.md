# The Star Mass Calculator (Frontend)

SPA на React, TypeScript, Vite и React-Bootstrap. Данные берутся только из mock-объектов (`src/modules/mock.ts`), состояние страниц хранится в самих компонентах (`useState`) и в адресной строке, менеджер состояний не используется.

Для запуска
```bash
npm install
npm run dev
```
Приложение будет доступно по ссылке: http://localhost:3001

## Меню

Нижняя панель `Navbar` из 4 пунктов:

| Пункт | Маршрут | Состояние |
|---|---|---|
| Лента | `/feed` | доступен |
| Добавить | `/add` | заглушка |
| Каталог | `/catalog` | доступен |
| Вход | `/login` | заглушка |

Пункты «Добавить» и «Вход» отображаются в меню, но пока недоступны: в этой версии работают только лента и каталог, страницы добавления и входа описаны ниже как следующий этап.

## Страницы

### Лента (`/feed`, `/feed/:id`)

Без `id` открывается первая опубликованная услуга, с `id` - выбранная. Если услуги нет или она не опубликована, показывается сообщение и кнопка «В каталог».

Элементы:
- видео на весь экран; если `videoUrl` пустой или не загрузился, воспроизводится видео по умолчанию;
- изображение; если `imageUrl` пустой или не загрузился, показывается изображение по умолчанию;
- справа: иконка лайка с количеством, средняя масса (M⨀), средняя светимость (L⨀);
- кнопка «Следующий» (стрелка вниз) - переход к следующей опубликованной услуге по порядку, после последней - к первой;
- внизу: название и описание, кнопка «ещё…» / «свернуть» разворачивает и сворачивает описание.

### Каталог (`/catalog`)

Плитка опубликованных услуг в 2 столбца. Карточка: изображение, название, количество лайков, кнопка «Подробнее»; клик по карточке или кнопке открывает ленту с этой услуги.

Фильтр по массе:
- два ползунка `min` и `max` (0-25 M⨀, шаг 0,1), минимум не может превысить максимум;
- кнопка «Найти» записывает значения в адрес (`/catalog?min=1&max=10`), поэтому фильтр сохраняется после запроса и при обновлении страницы;
- если ничего не найдено, выводится «По заданным параметрам ничего не найдено».

Услуги в статусах `draft` и `deleted` не отображаются.

### Добавление (`/add`)

Страница для создания новой услуги в два шага.
Шаг 1:
- поле «Название»;
- выбор файла изображения;
- выбор файла короткого видео;
- кнопка «Далее».

Шаг 2:
- поле «Краткое описание» (многострочное);
- поле «Масса, M⨀»;
- поле «Светимость, L⨀»;
- кнопка «Опубликовать», после неё открывается лента с новой услугой.

### Вход (`/login`)

Страница авторизации с одной формой и переключением между входом и регистрацией:
- поле «Имя пользователя»;
- поле «Пароль»;
- кнопка «Войти» (в режиме регистрации - «Зарегистрироваться»);
- ссылка «Нет аккаунта? Зарегистрироваться» / «Уже есть аккаунт? Войти» переключает режим;
- под заголовком выводится сообщение об ошибке, если данные неверны.
